# About the Course

## Purpose

**Information Security: A Self-Study Course from Beginner to Advanced** is a complete, free course designed so that an independent learner can progress from absolute beginner to advanced applied security **without classroom lectures, instructor demonstrations, paid software, or university infrastructure**. The same materials support instructors who wish to adopt the course for teaching.

## How the course is designed

- **Markdown-first.** Every lesson, lab, and assessment is plain Markdown in this repository — readable on GitHub without any website, and independent of the publishing theme.
- **Safety-first.** Offensive skills are taught only against local, isolated, deliberately vulnerable environments with synthetic data. The [Lab Safety Policy](./lab-safety-policy.md) is a graded gate, not an appendix.
- **Evidence-based assessment.** Progress is demonstrated through artifacts — captures, configurations, reports, detections — rather than memorization alone. See the [Assessment Guide](./assessment-guide.md).
- **Free tooling throughout.** Every lab uses free/open-source tools; the total course budget is $0 (see [Prerequisites](./prerequisites.md)).
- **Measurable outcomes.** Each module states observable learning outcomes mapped to the course-level outcomes in [Learning Outcomes](./learning-outcomes.md).
- **Version-aware references.** Standards and tool editions are cited with a verification date (see the [version table in the Course Roadmap](./course-roadmap.md#reference-and-version-policy)) so content can be kept current as NIST, OWASP, MITRE, CIS, and other bodies release updates.

## Structure at a glance

19 modules in four levels: **Foundations** (M01–M05) → **Core Technical Skills** (M06–M11) → **Practical Assessment & Defense** (M12–M15) → **Advanced & Capstone** (M16–M19). Start with the [Course Roadmap](./course-roadmap.md) or the [Module Index](./modules/README.md).
