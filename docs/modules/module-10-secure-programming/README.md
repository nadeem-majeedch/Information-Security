# Module 10 — Secure Programming and Software Security

> **Status:** Outline ready — full lesson content coming soon.
> **Level 2 · Core Technical Skills · Intermediate · Estimated time: 18–20 hours**

**Prerequisites:** [Module 09](../module-09-web-application-security/README.md) (vulnerability vocabulary); working knowledge of one programming language (see [Prerequisites](../../prerequisites.md)).

## What you will be able to do

- Apply the secure SDLC: security requirements, coded review, testing, and release gates.
- Find and fix 8 seeded weaknesses (injection, path traversal, hardcoded secrets, weak RNG, SSRF, and more).
- Run and interpret SAST, dependency, secret-scanning, and container-scanning tools; triage true vs. false positives.

## Deliverable & knowledge check

- **Portfolio pack:** patch set (diffs) for 8 fixes + pipeline log showing fail-then-pass on a planted issue.
- **Knowledge check:** 12-question quiz (8 MCQ + 4 code-review questions), pass at ≥ 80%. **→ [Module 10 quiz](../../assessments/level-2/quiz-m10.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
