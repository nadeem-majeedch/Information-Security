# Module 13 — Logging, Monitoring, and Security Operations

> **Status:** Outline ready — full lesson content coming soon.
> **Level 3 · Practical Assessment & Defense · Intermediate · Estimated time: 16–18 hours**

**Prerequisites:** [Module 04](../module-04-networking-fundamentals-for-security/README.md), [Module 05](../module-05-operating-system-and-endpoint-security/README.md); [Module 08](../module-08-network-security/README.md) recommended.

## What you will be able to do

- Configure meaningful logging (syslog/journald, Windows Event Log, application logs) with justified retention.
- Write detection rules for 6+ attack behaviors mapped to MITRE ATT&CK techniques.
- Triage simulated alerts: classify true/false positive, severity, and next actions using a playbook.

## Deliverable & knowledge check

- **Detection investigation:** logging architecture note + 6 tested detection rules with ATT&CK mapping + 5 completed triage worksheets (counts toward the graded *Defensive Investigations* component).
- **Knowledge check:** 12-question quiz (8 MCQ + 4 triage scenarios), pass at ≥ 80%. **→ [Module 13 quiz](../../assessments/level-3/quiz-m13.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
