# Course Modules — Index

All 19 modules in study order. Complete them sequentially; level gates require all prior-level modules to be finished (see [Progression rules](../course-roadmap.md#progression-rules-and-course-completion)).

> **Note:** **Level 1 (Modules 01–05) is complete** — full lessons with worked examples, labs, and knowledge checks. Modules 06–19 currently show their specification pages (outcomes, deliverables, links to the [Course Roadmap](../course-roadmap.md)) while their lesson content is being written.
