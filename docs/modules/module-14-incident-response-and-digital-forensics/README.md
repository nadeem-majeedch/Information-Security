# Module 14 — Incident Response and Digital Forensics

> **Status:** Outline ready — full lesson content coming soon.
> **Level 3 · Practical Assessment & Defense · Advanced · Estimated time: 18–20 hours**

**Prerequisites:** [Module 13](../module-13-logging-monitoring-and-security-operations/README.md), [Module 05](../module-05-operating-system-and-endpoint-security/README.md).

## What you will be able to do

- Write an incident response plan aligned with NIST SP 800-61 Rev. 3 (prepare → detect & analyze → contain/eradicate/recover → post-incident).
- Collect digital evidence in correct order of volatility and document chain of custody.
- Reconstruct an investigation timeline from disk, log, and filesystem artifacts.

## Deliverable & knowledge check

- **IR investigation:** IR plan (2–3 pages) + forensic timeline report from a synthetic evidence bundle + tabletop action log (counts toward the graded *Defensive Investigations* component).
- **Knowledge check:** 14-question quiz (9 MCQ + 5 applied sequencing questions), pass at ≥ 80%. **→ [Module 14 quiz](../../assessments/level-3/quiz-m14.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
