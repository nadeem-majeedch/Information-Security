# Module 11 — Threat Modeling and Security Architecture

> **Status:** Outline ready — full lesson content coming soon.
> **Level 2 · Core Technical Skills · Intermediate · Estimated time: 12–14 hours**

**Prerequisites:** Modules 01–10 — especially [Module 05](../module-05-operating-system-and-endpoint-security/README.md), [Module 07](../module-07-identity-and-access-management/README.md), and [Module 09](../module-09-web-application-security/README.md).

## What you will be able to do

- Produce a data-flow diagram with trust boundaries for a given application scenario.
- Apply STRIDE to every element and elicit 15+ distinct threats with mitigations and residual risk.
- Evaluate an architecture against zero-trust principles (never trust, always verify; least privilege; assume breach).

## Deliverable & knowledge check

- **Portfolio pack:** DFD image + threat table (risk-ranked with mitigations) + 1-page architecture review memo.
- **Knowledge check:** 10-question quiz + threat-model quality checklist (self-assessed), pass at ≥ 80%. **→ [Module 11 quiz](../../assessments/level-2/quiz-m11.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
