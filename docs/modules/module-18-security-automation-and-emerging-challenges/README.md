> **Status:** Outline ready — full lesson content coming soon.

## What you will be able to do

- Automate a recurring security task end-to-end (script → schedule → alert → report) with failure handling.
- Build a mini security-pipeline combining scanning, detection, and notification (security-as-code).
- Analyze an emerging challenge — AI/ML security, supply-chain attacks, or ransomware trends — with credible sources.

- **Portfolio pack:** automation script + run log with planted-event evidence + pipeline config/log + emerging-threat brief.
