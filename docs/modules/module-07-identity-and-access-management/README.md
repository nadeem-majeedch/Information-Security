# Module 07 — Identity, Authentication, Authorization, and Access Management

> **Status:** Outline ready — full lesson content coming soon.
> **Level 2 · Core Technical Skills · Intermediate · Estimated time: 12–14 hours**

**Prerequisites:** [Module 05](../module-05-operating-system-and-endpoint-security/README.md), [Module 06](../module-06-cryptography/README.md).

## What you will be able to do

- Differentiate identification, authentication, authorization, and accounting, with failure examples for each.
- Compare authentication methods (passwords, passkeys/FIDO2, TOTP) against NIST SP 800-63-4 guidance.
- Implement least privilege and role-based access control in a lab directory and web application.

## Deliverable & knowledge check

- **Portfolio pack:** IAM design note for a 5-person team + RBAC/MFA lab evidence.
- **Knowledge check:** 12-question quiz (8 MCQ + 4 scenario), pass at ≥ 80%. **→ [Module 07 quiz](../../assessments/level-2/quiz-m07.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
