# Module 19 — Integrated Capstone Project

> **Status:** Outline ready — full lesson content coming soon.
> **Level 4 · Advanced Security & Capstone · Advanced · Estimated time: 30–40 hours**

**Prerequisites:** Modules 01–18. Complete Levels 1–3 first; [Module 16](../module-16-cloud-and-infrastructure-security/README.md)–[18](../module-18-security-automation-and-emerging-challenges/README.md) strongly recommended.

## What you will be able to do

The capstone integrates the whole pathway: design and threat-model a small-organization system, harden it, assess it under written authorization, defend it with logging/detections/response, and close with a privacy note and lessons learned.

## The five stages

| Stage | Focus |
|---|---|
| A | Architecture & STRIDE threat model |
| B | Implementation: hardened hosts, segmentation, IAM, TLS |
| C | Authorized assessment report of the built environment |
| D | Defend: logging, 4 detections, simulated incident + forensic timeline |
| E | Privacy note (DPIA-lite) + lessons learned + reflection |

**Assessment:** graded with the capstone rubric in the [Assessment Guide](../../assessment-guide.md) — pass at ≥ 60% overall with every stage meeting the stage standard (≥ Proficient on 4 of 5 criteria; no stage below Developing).

The full specification is in the [Course Roadmap](../../course-roadmap.md).

**Scoring instrument:** [Capstone Assessment Rubric (standalone)](../../assessments/final/capstone-rubric.md) — per-stage criteria, stage standards, and a self-assessment worksheet. Optional broader knowledge check: [CAP-ADV advanced final](../../assessments/final/advanced-final.md).

**Project brief:** [M19 Capstone Project](../../capstone/README.md) — overview and student brief, two alternative scenarios, the seven-stage workflow with gates, report/risk-register/threat-model/findings templates, the [seven-dimension rubric](../../capstone/rubric.md), and [completion checklists](../../capstone/checklists.md).
