# Module 08 — Network Security: Perimeter, Segmentation, and Secure Protocols

> **Status:** Outline ready — full lesson content coming soon.
> **Level 2 · Core Technical Skills · Intermediate · Estimated time: 14–16 hours**

**Prerequisites:** [Module 04](../module-04-networking-fundamentals-for-security/README.md), [Module 05](../module-05-operating-system-and-endpoint-security/README.md).

**All scanning and IDS testing targets are lab IPs only** — see the [Lab Safety Policy](../../lab-safety-policy.md).

## What you will be able to do

- Design a segmented lab network with justified firewall rules and verify allowed/blocked flows.
- Configure host- and network-based firewalls and deploy an IDS (Suricata/Snort) with readable alerts.
- Evaluate secure protocols and recommend replacements for plaintext services.

## Deliverable & knowledge check

- **Portfolio pack:** network diagram + firewall rule table with justifications + IDS alert triage notes.
- **Knowledge check:** 12-question quiz (8 MCQ + 4 rule-review scenarios), pass at ≥ 80%. **→ [Module 08 quiz](../../assessments/level-2/quiz-m08.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
