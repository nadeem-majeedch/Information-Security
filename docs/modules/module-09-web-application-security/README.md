# Module 09 — Web Application Security (OWASP Top 10:2025)

> **Status:** Outline ready — full lesson content coming soon.
> **Level 2 · Core Technical Skills · Intermediate · Estimated time: 18–20 hours**

**Prerequisites:** [Module 04](../module-04-networking-fundamentals-for-security/README.md) (HTTP), [Module 06](../module-06-cryptography/README.md) (TLS basics), [Module 07](../module-07-identity-and-access-management/README.md) (sessions/auth).

**Targets are local, deliberately vulnerable apps only** (Juice Shop, DVWA, WebGoat) — never public sites. See the [Lab Safety Policy](../../lab-safety-policy.md).

## What you will be able to do

- Explain each OWASP Top 10:2025 category with root cause and prevention.
- Demonstrate at least 6 vulnerability classes across 5+ categories in local lab apps.
- Write professional vulnerability reports and map findings to ASVS requirements and CVSS v4.0.

## Deliverable & knowledge check

- **Portfolio pack:** web assessment report (≥ 6 evidenced findings) + challenge log + ASVS mapping.
- **Knowledge check:** 14-question quiz (10 MCQ + 4 scenario), pass at ≥ 80%. **→ [Module 09 quiz](../../assessments/level-2/quiz-m09.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
