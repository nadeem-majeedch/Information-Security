# Module 06 — Cryptography and Applied Cryptography

> **Status:** Outline ready — full lesson content coming soon.
> **Level 2 · Core Technical Skills · Intermediate · Estimated time: 14–16 hours**

**Prerequisites:** [Module 01](../module-01-information-security-foundations/README.md); basic terminal comfort from Modules 04–05.

## What you will be able to do

- Distinguish symmetric, asymmetric, and hash algorithms with use cases and weaknesses.
- Execute correct key handling: generate keypairs, encrypt/decrypt, sign/verify using open tooling.
- Detect common cryptographic misuses (ECB mode, static IVs, MD5/SHA-1 for integrity, hard-coded keys) and explain the fix.

## Deliverable & knowledge check

- **Portfolio pack:** crypto lab notebook (commands + outputs) + misuse analysis sheet (6 findings with weakness IDs).
- **Knowledge check:** 14-question quiz (10 MCQ + 4 applied), pass at ≥ 80%. **→ [Module 06 quiz](../../assessments/level-2/quiz-m06.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
