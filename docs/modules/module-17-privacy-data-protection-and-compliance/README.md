# Module 17 — Privacy, Data Protection, Risk Management, and Compliance

> **Status:** Outline ready — full lesson content coming soon.
> **Level 4 · Advanced Security & Capstone · Advanced · Estimated time: 12–14 hours**

**Prerequisites:** [Module 02](../module-02-threats-vulnerabilities-risk-and-controls/README.md), [Module 03](../module-03-governance-policy-ethics-and-law/README.md); [Module 11](../module-11-threat-modeling-and-security-architecture/README.md) recommended.

## What you will be able to do

- Distinguish privacy, confidentiality, and security; classify data types in a scenario.
- Build a data-flow map and complete a DPIA-style worksheet for a small system.
- Map controls across NIST CSF 2.0, CIS v8.1, and ISO/IEC 27001:2022, and identify gaps.

## Deliverable & knowledge check

- **Portfolio pack:** data-flow map + completed DPIA + control-mapping table with gap analysis.
- **Knowledge check:** 12-question quiz (8 MCQ + 4 scenario), pass at ≥ 80%. **→ [Module 17 quiz](../../assessments/level-4/quiz-m17.md)**

The complete specification — core concepts, lab scenarios, completion criteria, and references — is in the [Course Roadmap](../../course-roadmap.md).
