# Module 16 — Cloud and Infrastructure Security

> **Status:** Outline ready — full lesson content coming soon.
> **Level 4 · Advanced Security & Capstone · Advanced · Estimated time: 16–18 hours**

**Prerequisites:** [Module 05](../module-05-operating-system-and-endpoint-security/README.md), [Module 08](../module-08-network-security/README.md), [Module 11](../module-11-threat-modeling-and-security-architecture/README.md).

## What you will be able to do

- Explain the shared responsibility model across IaaS/PaaS/SaaS and assign responsibility correctly.
- Produce a hardened container image (non-root, no embedded secrets, resource limits) with a clean vulnerability scan.
- Audit IaC configurations for misconfigurations and fix them.

## Deliverable & knowledge check

- **Portfolio pack:** hardened image + before/after scans + IaC audit sheet (8 issues) + architecture review memo.
- **Knowledge check:** 12-question quiz (8 MCQ + 4 shared-responsibility scenarios), pass at ≥ 80%. **→ [Module 16 quiz](../../assessments/level-4/quiz-m16.md)**

Cloud labs run locally with free tooling — no paid cloud account is required. The complete specification is in the [Course Roadmap](../../course-roadmap.md).
